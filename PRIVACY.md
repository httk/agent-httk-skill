# Privacy Policy for the httk skill

Effective date: August 7, 2026

This policy applies to the `httk` skill and plugin distributed from the
[agent-httk-skill repository](https://github.com/httk/agent-httk-skill).

## Data handling

The `httk` skill is a static bundle of instructions, reference documentation,
and presentation assets. It does not include an MCP server, hosted service,
user account system, analytics, telemetry, cookies, or other tracking code.
The skill itself does not collect, receive, store, process, sell, or share
personal data, prompts, files, or usage information, and it does not send such
information to the httk project.

## Host platforms and external resources

The application in which you install or use the skill, such as ChatGPT,
Claude, or another agent host, may process your prompts, files, and usage data
under its own privacy policy. The skill may describe commands that access
resources chosen by the user and contains links to external documentation and
source repositories. Access to those resources is governed by the policies of
the applicable sites and services. Those platforms and external services are
outside the scope of this policy.

## Changes and contact

If the skill later adds a service or another feature that handles user data,
this policy will be updated before that feature is released. The publisher is
Rickard Armiento, who can be contacted at
[rickard-gpg@armiento.net](mailto:rickard-gpg@armiento.net). Questions can
also be submitted through the
[repository issue tracker](https://github.com/httk/agent-httk-skill/issues).
